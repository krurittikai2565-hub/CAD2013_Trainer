    ยินดีต้อนรับสู่ห้องฝึกเขียนแบบ

    ฐานที่ 1–6 · การใช้งานโปรแกรมเขียนแบบเบื้องต้น

    แนะนำให้เริ่มที่ ฐานที่ 1–2 (บทนำ) อ่านพื้นฐานและตอบคำถามท้ายหัวข้อเพื่อเก็บคะแนน ก่อนไปฝึกปฏิบัติฐานที่ 3–6 — เริ่มเลยไหม?

    • ส่วนประกอบหน้าจอ, Function Keys, การใช้เมาส์
    • OSNAP, Layer, การเลือกวัตถุ และระบบพิกัด
    • ตอบคำถามท้ายแต่ละหัวข้อถูก ได้หัวข้อละ 10 คะแนน
    บทนำ · การใช้โปรแกรมเขียนแบบสถาปัตยกรรมเบื้องต้นฐานที่ 1–2 · อ่านแล้วตอบคำถามท้ายหัวข้อเพื่อเก็บคะแนน
    🔒 ระบบหลังบ้าน

    เข้าสู่ระบบผู้ดูแล

    ดูและแก้ไขข้อมูลนักศึกษา คะแนน และแบบทดสอบ

    ⚙ ตั้งค่าการเชื่อมต่อฐานข้อมูล

    เชื่อมเว็บนี้กับ Google Sheet สำหรับเก็บการลงทะเบียน คะแนน และแบบทดสอบ

    1. เปิด Google Sheet ที่จะใช้เก็บข้อมูล → เมนู ส่วนขยาย (Extensions) › Apps Script
    2. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดของระบบนี้ → กดบันทึก (💾)
      แนะนำให้แก้บรรทัด const ADMIN_PASSWORD = 'cad2013admin'; เป็นรหัสผ่านของคุณก่อน Deploy
    3. กด Deploy › New deployment → เลือกประเภท Web app → Execute as: Me · Who has access: Anyone → Deploy → อนุญาตสิทธิ์ → คัดลอก Web app URL (ลงท้ายด้วย /exec)
      ถ้าเคย Deploy แล้วและแค่อัปเดตโค้ด: Deploy › Manage deployments › ✏️ › Version: New version (URL เดิม)
    4. วาง Web app URL แล้วทดสอบการเชื่อมต่อ
    5. นำไปใช้
      “ใช้ในเครื่องนี้” มีผลเฉพาะเบราว์เซอร์นี้ · ให้นักศึกษาทุกคนใช้ได้ → ดาวน์โหลดไฟล์เว็บที่ตั้งค่าแล้ว ไปแทนไฟล์เดิม
      เปิดไฟล์จากเครื่องจึงสร้างไฟล์ให้อัตโนมัติไม่ได้ — เปิดไฟล์เว็บด้วย Notepad ค้นหาบรรทัด const SHEET_API_URL= แล้วแทนที่ด้วยบรรทัดนี้:
